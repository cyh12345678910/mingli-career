# 排盘流程

本模块负责完成八字排盘并提取职业决策所需的关键信息。**排盘由 liki-bazi 引擎完成**，本模块只做编排与信息提取。

## 步骤

### 1. 检查依赖

确认 `liki-bazi` 已安装（`.trae/skills/liki-bazi` 存在）。未安装则提示：

```
请先安装排盘引擎：npx skills add ml8s/liki/skills/liki-bazi -y
```

### 2. 收集出生信息

| 信息 | 说明 |
|------|------|
| 出生日期 | 公历（阳历）年月日 |
| 出生时间 | 尽量精确到分钟；只知"上午/下午"可先给大概 |
| 出生城市 | 用于真太阳时校正（经度），精确到市/县 |
| 性别 | 大运顺逆排法不同 |

**时辰不确定时**：进入 liki-bazi 的考时流程（候选时辰 2-3 个 + 人生大事 3-5 件，逐盘核验反推）。

### 3. 调用排盘

按 liki-bazi 标准流程：

```
city_coords(城市) → 经度
full_paipan(gregorian, 性别, 经度) → pan
```

### 4. 提取关键信息

从 `pan` 提取（缺失则回查 liki-bazi 的 query 结果）：

- [ ] 日主与强弱
- [ ] 五行分布（各五行数量，所缺/过旺）
- [ ] 喜用神（用/喜/忌，三派聚合）
- [ ] 十神结构（透干与藏干）
- [ ] 当前大运干支与起止年份（**必须来自 full_paipan，禁止自行推算**）
- [ ] 当前及未来数年流年干支

### 5. 输出

输出排盘摘要，供 career / city / timing 模块使用：

```
日主：己土（身强）
五行：土4 木3 火2 金2 水0
用神：水（调候+财星）  喜：木  忌：火、土
十神：金=食伤（透干） 水=财 木=官杀 火=印 土=比劫
大运：戊辰劫财（2025-2035）
```

## 红线

- 经度未知 → 先问出生地，禁止用默认经度静默排盘
- 大运/大限干支与起止年龄必须来自 full_paipan，严禁自行推算
- 计算结果一律经工具获取，禁止凭训练知识臆造
