# 城市 / 方位推荐

本模块基于喜用神，给出方位排序与城市推荐。这是本技能的核心原创能力——把"喜用神 → 方位 → 城市五行"链路内置。

## 方位五行

| 方位 | 五行 |
|------|------|
| 东方 | 木 |
| 南方 | 火 |
| 西方 | 金 |
| 北方 | 水 |
| 中央 | 土 |
| 东南 | 木 |
| 西南 | 土 |
| 东北 | 土 |
| 西北 | 金 |

## 推荐逻辑

1. 取喜用神（用/喜/忌）
2. 用神五行 → 对应方位 → 吉
3. 忌神五行 → 对应方位 → 忌
4. 结合城市五行映射表（`references/wuxing-city.md`）给出具体城市
5. 可结合奇门（如 liki-divination 的开门落宫）做方位级佐证

## 判断规则

- **用神方位** = 首选（如喜水 → 北方；喜木 → 东方/东南）
- **忌神方位** = 避忌（如忌火 → 南方慎入；忌土 → 西南/东北慎入）
- 城市五行 = 方位五行 + 地貌/水文修正（临海补水、山岗增土、江河增水）
- 给出"推荐城市 + 匹配点 + 行业匹配"三段式输出

## 输出示例

```
命主喜水（财）、木（官杀），忌火土。
方位排序：东南（木）＞ 北方（水）＞ 东方（木）；避开南方（火）、西南（土）。
推荐城市：
🥇 杭州/上海/苏州（东南·木水）—— 财官双得，行业腹地
🥈 北京（北方·水）—— 财旺大平台
暂避：广州/深圳（南方·火）、成都/重庆（西南·土）
```

## 注意事项

- 城市五行映射为传统文化视角的归纳，具体论法因流派而异，输出时注明"参考"
- 命理方位建议是决策参考之一，最终结合行业机会、家庭、成本综合判断
