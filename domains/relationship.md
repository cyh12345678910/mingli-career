# 合盘 / 人际关系分析

本模块用于分析同事、合伙人、下属的命理合参关系——**命理结论为传统文化视角，仅供参考，不构成人事决策建议**。

## 双体系合盘方法

### 八字侧（side=bazi）

| 合盘维度 | 含义 | 命理依据 |
|----------|------|----------|
| 日主合化 | 两人日主合化（如甲己合化土）→ 容易相处 | 《三命通会·论合化》 |
| 喜用神互补 | A 的用神是 B 的喜神 → 互相成就 | 同频共振 |
| 喜用神相克 | A 的忌神是 B 的用神 → 互相压制 | 性格冲突 |
| 十神关系 | A 的官杀 = B 的比劫 → B 不服 A 管 | 权力冲突 |
| 纳音相克 | 两人纳音相克 → 气场不合 | ⚠️ 待核 |

### 紫微侧（side=ziwei）

| 合盘维度 | 含义 | 命理依据 |
|----------|------|----------|
| 命宫主星三合 | 两人命宫主星三合 → 互相欣赏 | 《紫微斗数全书·论合盘》 |
| 官禄宫四化互动 | A 的官禄宫四化影响 B 的命宫 → 事业牵动 | 《紫微斗数全书·论四化》 |
| 夫妻宫互涉 | A 的夫妻宫星曜落 B 的命宫 → 合作有缘 | 《紫微斗数全书·论夫妻宫》 |

## 常见场景判断

### 同事关系

```
合参框架：
1. 八字侧：对比两人日主、喜用神、十神关系
2. 紫微侧：对比命宫主星、官禄宫、交友宫
3. 合参输出：
   - 用神互补 + 紫微三合 = 同频共振，好同事
   - 喜忌相克 + 紫微犯忌 = 气场不合，避免深交
```

### 合伙人关系

```
合参框架：
1. 八字侧：财星关系（A 财 = B 喜神 → 互相生财）
2. 紫微侧：财帛宫+官禄宫互动
3. 红线：比劫过旺的两人合伙 → 夺财，风险极高
```

### 上下级关系

```
合参框架：
1. 八字侧：官杀关系（A 的官杀 = B 的日主 → B 服 A 管）
2. 紫微侧：命宫→交友宫互动（上级命宫三合下属交友宫 → 下属跟随）
```

## 判断规则

1. **先排双盘**：为每个人独立完成八字 + 紫微排盘
2. **分侧对比**：八字侧对比八字侧、紫微侧对比紫微侧，**不跨体系对比**
3. **合参裁决**：两侧同向为强信号，两侧相反则并列说明
4. **输出必注明**：命理结论仅供参考，不构成人事决策建议

## 红线

- **绝对不能**因为合盘"不好"而建议用户解雇/跳槽/疏远某人
- 合盘结果**仅供个人参考**，不得用于歧视、排挤等行为
- 输出必须带免责声明

## 输出示例

```
═════ 同事合盘：A（己土身强）vs B（乙木身弱）═════

八字侧：
A 的忌神是木，B 的日主是木 → A 的忌神是 B 的本源
→ 命理提示：A 可能不自觉地压制 B（忌神的排斥效应）⚠️

紫微侧：
A 命宫紫微在午，B 命宫天机在亥 → 无三合无冲
→ 紫微视角：普通同事，无特别牵引

合参：八字有弱压制信号 + 紫微无强牵引 → 建议 A 注意不要无意中给 B 压力

⚠️ 声明：此为传统文化视角参考，不代表现实人际关系必然如此。
```
