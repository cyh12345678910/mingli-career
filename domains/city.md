# 城市 / 方位推荐（双体系合参）

本模块基于喜用神（八字侧）和紫微大限流年方位（紫微侧），给出方位排序与城市推荐。

## 方位五行（双体系共用）

| 方位 | 五行 | 古籍依据 |
|------|------|----------|
| 东方 / 东北 | 木 | 《五行大义》"东方甲乙木" |
| 南方 | 火 | 《五行大义》"南方丙丁火" |
| 西方 / 西北 | 金 | 《五行大义》"西方庚辛金" |
| 北方 | 水 | 《五行大义》"北方壬癸水" |
| 中央 / 西南 | 土 | 《五行大义》"中央戊己土" |

## 八字侧推荐逻辑

1. 取喜用神（用/喜/忌，**必须来自 liki 八字引擎**）
2. 用神五行 → 对应方位 → 吉
3. 忌神五行 → 对应方位 → 忌
4. 结合 `references/wuxing-city.md` 给出具体城市
5. 城市五行 = 方位五行 + 地貌/水文修正（临海补水、山岗增土、江河增水）

## 紫微侧推荐逻辑

紫微斗数中，**迁移宫**与**命宫三方四正**的星曜和四化决定外出吉凶：

1. 取紫微本命盘迁移宫主星 + 大限迁移宫 + 流年迁移宫
2. 迁移宫有化禄/化权/左辅右弼/禄马 → 外出有利
3. 迁移宫有化忌/擎羊陀罗/火星铃星 → 外出不利
4. 紫微方位论法参考《紫微斗数全书·论迁移》

## 双体系合参

| 情况 | 合参结论 |
|------|----------|
| 八字用神方位 = 紫微迁移宫吉 | **强信号**，推荐度 ⭐⭐⭐⭐⭐ |
| 八字用神方位 ≠ 紫微迁移宫吉 | 并列说明，建议结合行业机会再决定 |
| 八字忌神方位 + 紫微迁移宫凶 | **强忌信号**，强烈不推荐 |

## 判断规则

- **用神方位** = 首选（如喜水 → 北方；喜木 → 东方/东南）
- **忌神方位** = 避忌（如忌火 → 南方慎入；忌土 → 西南/东北慎入）
- 城市五行标注流派分歧（`⚠️` 标记）的，列出两种论法
- 给出"推荐城市 + 匹配点 + 行业匹配"三段式输出
- 可结合奇门（如 liki-divination 的开门落宫）做方位级佐证

```
═════ 合参推荐 ═════
🥇 杭州/上海/苏州（东南·木水）—— 财官双得 + 紫微迁移宫化禄 ⭐⭐⭐⭐⭐
🥈 北京（北方·水）—— 财旺大平台 ⭐⭐⭐⭐
⚠️ 深圳（南方·火，临海补水）—— 八字忌火但紫微无凶，可酌情

行业匹配：杭州 → 电商/互联网（木+水）；北京 → 金融/体制（水+金）
```

## 注意事项

- 城市五行映射为传统文化视角的归纳，具体论法因流派而异，输出时注明"参考"
- 命理方位建议是决策参考之一，最终结合行业机会、家庭、成本综合判断
- 有 `⚠️ 流派分歧` 标记的城市，列出两种论法供用户参考
