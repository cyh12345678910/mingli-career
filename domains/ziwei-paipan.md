# 紫微斗数排盘流程

本模块负责紫微斗数侧的排盘与信息提取。**排盘由 liki 引擎完成**（`side=ziwei`），本模块只做编排与信息提取。

八字侧排盘见 `paipan.md`，两侧合参与裁决见 SKILL.md。

## 步骤

### 1. 前置依赖

同八字侧排盘（`paipan.md`），确认 liki MCP 端点可用。

### 2. 收集出生信息

紫微排盘**需要农历**（liki engine 自动公历→农历换算，Agent 无需手动换算）：

| 信息 | 说明 |
|------|------|
| 出生日期 | 公历 → liki 自动转农历（含闰月处理） |
| 出生时间 | 尽量精确到分钟 → liki 自动定时辰安星 |
| 出生城市 | 用于真太阳时校正（经度） |
| 性别 | 紫微大限顺逆排法不同 |

### 3. 调用紫微排盘

```
紫微侧（side=ziwei）：
  full_paipan(公历, 性别, 经度, side=ziwei) → 本命盘（十二宫+大限+四化）
  extract_factors(本命盘) → 因子快照
```

liki 紫微侧会自动处理：
- 公历→农历换算（含闰月边界）
- 真太阳时校正（经度 + 均时差）
- 星曜亮度流派（文墨、传统等，liki 默认传统）
- 晚子时换日（23:00–23:59 按次日）
- 十二神煞（本命按生年支、流年按流年支）

### 4. 提取关键信息

- [ ] 命宫主星（紫微/天机/天府/太阳/武曲/天同/廉贞/七杀/破军/贪狼/巨门/太阴/天相/天梁）
- [ ] 命宫三方四正（会集的主星 + 辅星 + 化忌/化禄/化权/化科）
- [ ] 命宫对宫（迁移宫主星，决定外出吉凶）
- [ ] 当前大限主星 + 起止年份（**必须来自 liki，禁止自行推算**）
- [ ] 大限四化
- [ ] 生年四化（禄权科忌各落何宫）
- [ ] 格局判定（紫府同宫/日月并明/七杀朝斗/杀破狼/府相同宫/机梁加会等，liki patterns 规则库）

### 5. 输出紫微排盘摘要

```
═════ 紫微视角（side=ziwei）═════
命宫：紫微在午（帝王格）
三方四正：天府+天相同宫，左辅右弼夹，文昌文曲对宫
命宫四化：紫微化权（守命）、天府化科（守库）
迁移宫：武曲庙 + 化禄 + 禄马交驰 → 外出大利
当前大限：紫微大限（2022-2032）
大限四化：紫微化权、武曲化禄
生年四化：破军化禄、巨门化权、太阴化科、贪狼化忌
格局：紫府同宫格 ✅ + 禄马交驰格 ✅
```

## 红线

- 农历换算**必须由 liki 完成**，Agent 禁止自行换算农历/闰月
- 大限干支与起止年份**必须来自 liki 输出**，严禁自行推算
- 星曜亮度、四化、格局判定**全部经 liki patterns 规则库**，禁止凭训练知识臆造
- 紫微侧断语**不得混用八字因子**（如不得用八字十神解释紫微主星含义）
- 排盘失败 → 提示用户重试，**不降级查表**
