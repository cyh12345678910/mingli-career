## 格局组合示例

### 例 1：紫微在午 + 天府在申 = 紫府同宫 + 日月并明

```
官禄宫：紫微（午，化权）+ 天府（申，化科）+ 日月三合
→ 帝王格 + 日月并明
→ 职业方向：大平台一把手、公务员、央企高管
→ 收入模式：权+名兼得
```

### 例 2：七杀在寅 + 紫微在申对宫 = 七杀朝斗

```
官禄宫：七杀（寅）+ 紫微对宫 + 杀破狼三合
→ 七杀朝斗格
→ 职业方向：技术负责人、独立创业、外派干部
→ 注意：七杀主变动，事业上多转折
```

### 例 3：杀破狼在亥位

```
官禄宫：贪狼 + 破军 + 七杀三合（亥位）
→ 杀破狼格
→ 职业方向：改革派、研发创新、新业态
→ 周期：每 10 年一次大变动（杀破狼每 10 年轮值）
```
