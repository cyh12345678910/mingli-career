# 事业方向分析

本模块把命局十神结构翻译成职业方向建议。

## 十神 → 事业画像

| 十神 | 事业指向 | 典型岗位 |
|------|----------|----------|
| 食伤透干 | 技术、才艺、创造、攻坚 | 研发、算法、设计、内容、销售 |
| 偏印旺 | 技术专研、特殊技能 | 工程、研发、医疗技术、体育 |
| 食神制杀 | 有胆识不鲁莽，攻坚型 | 项目攻坚、技术负责人 |
| 正官/官杀旺 | 管理、体制、大平台 | 管理岗、公务员、央企 |
| 财星旺 | 流动、交易、积累 | 金融、贸易、物流、数据 |
| 比劫旺 + 伤官 | 自主、合伙 | 创业、自营、合伙 |
| 官禄天马/迁移宫动 | 外出发展、奔波 | 出差型、驻外、多基地协同 |

## 岗位性质 → 十神映射（核心工具）

判断一个岗位是否"顺势"，先把岗位性质映射到十神，再对照喜忌：

| 岗位性质 | 对应十神 | 对命局影响 |
|----------|----------|------------|
| 验证/把关/重复/文书/管理 | 印星 | 印为忌者 → 压制才华（印夺食伤）、夺财 |
| 创造/技术/攻坚/表达 | 食伤 | 食伤为用者 → 才华泄秀，最利 |
| 流动/交易/金融/数据 | 财 | 财为喜者 → 补财补命 |
| 平台/体制/晋升 | 官杀 | 官杀为用者 → 事业空间 |
| 竞争/合伙/体力 | 比劫 | 身强可担，但忌比劫夺财 |

## 判断规则

1. 先定日主强弱与喜用神
2. 把候选岗位映射到十神
3. **用神性质岗位 = 顺势**（推荐），**忌神性质岗位 = 逆势**（提示风险）
4. 给出"为什么当前岗位没前途 / 为什么某岗位契合"的命理依据

## 输出示例

```
测试岗属"印星"性质（验证/把关），印是你的忌神 → 印夺食伤（压才华）+ 印夺财。
研发岗属"食伤+偏印"性质（创造/钻研），食伤透干是你的用神 → 双用神共振，最契合。
结论：从测试转研发 = 弃忌从用，方向正确。
```
