# 健康提示（与职业相关）

本模块从命理角度给出健康提示——**⚠️ 命理结论仅供参考，不构成医疗诊断。任何健康问题请咨询专业医师。**

健康分析为职业决策的辅助维度：如果某岗位性质会加剧命理上的健康隐患，应提示风险。

## 八字侧：五行 → 脏腑

> 出处：《黄帝内经·素问》"东方甲乙木……南方丙丁火……中央戊己土……西方庚辛金……北方壬癸水" + 《渊海子平》"五行主五脏"

| 五行 | 对应脏腑 | 对应职业风险 | 古籍依据 |
|------|----------|--------------|----------|
| 木（胆/肝） | 肝胆 | 熬夜、压力大、情绪积压 → 肝胆问题 | 《素问·阴阳应象大论》 |
| 火（心/小肠） | 心脏、血压 | 加班、久坐、高糖 → 心血管问题 | 《素问·阴阳应象大论》 |
| 土（脾/胃） | 脾胃、消化 | 饮食不规律、久坐 → 肠胃问题 | 《素问·阴阳应象大论》 |
| 金（肺/大肠） | 呼吸系统、皮肤 | 空气污染、久坐 → 呼吸问题 | 《素问·阴阳应象大论》 |
| 水（肾/膀胱） | 肾脏、泌尿系统 | 熬夜、久坐憋尿、纵欲 → 肾亏 | 《素问·阴阳应象大论》 |

### 判断规则（八字侧）

1. **弱五行 = 需要留意的脏腑**（如八字木弱 → 肝胆弱）
2. **忌神五行过旺 = 容易受伤的脏腑**（如忌火而火旺 → 心脏血压）
3. **调候不足 = 系统风险**（如生于夏季调候水不足 → 心火旺）

## 与职业决策的关联

```
示例：命主八字火弱（心脏弱）+ 紫微疾厄宫太阳化忌（心脏/眼睛）
→ 合参：心脏为双体系弱项
→ 职业风险提示：
  ❌ 避免长期高强度加班（心脏负荷大）
  ❌ 避免高温环境工作（火弱火旺反伤）
  ✅ 适合有节奏、能休息的工作环境
```
