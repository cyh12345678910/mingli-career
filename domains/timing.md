# 时机节奏

本模块结合大运流年，判断职业动作（内转/跳槽/升迁/创业）的"攻守"窗口。

## 攻守框架

| 大运/流年性质 | 策略 | 动作 |
|---------------|------|------|
| 用神大运（官杀/财/食伤） | **攻** | 跳槽、升迁、创业、大动作 |
| 忌神大运（比劫/印旺） | **守** | 内转、稳守积累、防破财 |
| 流年用神引动 | 机会窗口 | 抓住应期（合化用神、三合局、贵人） |
| 流年忌神冲用 | 忌动 | 避免裸辞、大变动、冲动决策 |

## 关键信号

| 流年信号 | 含义 |
|----------|------|
| 用神被合化（如忌神印被食伤合走化财） | 机会应期——"技术变钱" |
| 用神三合局（如卯未合木） | 事业引动——晋升/平台跃升 |
| 天乙贵人 | 贵人牵线、稳妥成行 |
| 冲用神（如酉卯冲） | 忌动——变动之年谨慎 |
| 天喜/红鸾 | 喜事临门（换岗成功也是喜） |
| 自刑（如午午自刑） | 内心躁动、想变动 |

## 判断规则

1. 大运定基调（攻/守），流年定应期（何时动）
2. 忌神大运内：优先"内转/稳"等低风险动作；跳槽放用神流年
3. 给出逐年窗口表（何时内转、何时跳槽、何时忌动）

## 输出示例

```
当前戊辰劫财运（2025-2035）→ 宜守，防比劫夺财。
2026 丙午：丙辛合化水（忌神被合走、财星引出）+ 天喜 → 内转窗口
2027 丁未：未卯三合木局（官杀用神引动）→ 晋升/跳槽最佳
2028 戊申：天乙贵人 → 贵人年，再上台阶
2029 己酉：酉卯冲用神 → 忌动
```

## 红线

- 大运/大限干支与起止年龄必须来自 full_paipan，严禁自行推算
- 流年分析使用 liki-bazi 的 yearly_range 结果，禁止凭训练知识臆造
