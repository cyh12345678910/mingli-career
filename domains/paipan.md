# 排盘流程（八字 + 紫微双体系）

本模块负责完成八字与紫微双体系排盘。**排盘由 liki 引擎完成**（`engine-mcp` + `counsel-mcp`），本模块只做编排与信息提取。

## 步骤

### 1. 检查依赖

确认 liki 已安装（MCP `tools/list` 返回 `engine-mcp` + `counsel-mcp` 端点可用）。未安装则提示：
```
请先安装命理引擎：npx skills add ml8s/liki -y
```

### 2. 收集出生信息

| 信息 | 说明 |
|------|------|
| 出生日期 | 公历（阳历）年月日 |
| 出生时间 | 尽量精确到分钟；只知"上午/下午"可先给大概 |
| 出生城市 | 用于真太阳时校正（经度），精确到市/县 |
| 性别 | 大运顺逆排法不同；紫微也区分男女 |

**时辰不确定时**：进入 liki 考时流程（候选时辰 2-3 个 + 人生大事 3-5 件，逐盘核验反推）。

### 3. 调用排盘（双体系并列）

```
八字侧（side=bazi）：
  city_coords(城市) → 经度
  full_paipan(gregorian, 性别, 经度) → 本命盘（四柱+大运）
  extract_factors(本命盘) → 因子快照

紫微侧（side=ziwei）：
  公历 → 农历换算（liki engine 自动）
  full_paipan(农历, 性别) → 本命盘（十二宫+大限）
  extract_factors(本命盘) → 因子快照
```

### 4. 提取关键信息

#### 八字侧（side=bazi）

- [ ] 日主与强弱
- [ ] 五行分布（各五行数量，所缺/过旺）
- [ ] 喜用神（用/喜/忌，**liki counsel 层已计算三派聚合结论**，禁止自行推算）
- [ ] 十神结构（透干与藏干）
- [ ] 当前大运干支与起止年份（**必须来自 liki 输出，禁止自行推算**）
- [ ] 当前及未来数年流年干支（来自 `yearly_range`）

#### 紫微侧（side=ziwei）

- [ ] 命宫主星
- [ ] 命宫三方四正（会集主星 + 辅星 + 四化）
- [ ] 当前大限主星与起止年份（**必须来自 liki 输出，禁止自行推算**）
- [ ] 生年四化 + 大限四化
- [ ] 格局判定（紫府同宫/七杀朝斗/杀破狼等，liki patterns 规则库）

### 5. 输出双体系排盘摘要

```
═════ 八字视角（side=bazi）═════
日主：己土（身强）
五行：土4 木3 火2 金2 水0
用神：水（调候+财星）  喜：木  忌：火、土
大运：戊辰劫财（2025-2035）

═════ 紫微视角（side=ziwei）═════
命宫：紫微在午（帝王格）
三方四正：天府+天相同宫，左辅右弼夹
大限：紫微大限（2022-2032）
生年四化：破军化禄、巨门化权、太阴化科、贪狼化忌
格局：紫府同宫格 ✅
```

## 红线

- 经度未知 → 先问出生地，**禁止用默认经度静默排盘**
- 大运/大限干支与起止年份**必须来自 liki 输出**，严禁自行推算
- 计算结果一律经 liki 工具获取，**禁止凭训练知识臆造**
- 八字侧断语不得混用紫微因子、紫微侧不得混用八字因子
- 排盘失败 → 提示用户重试，**不降级查表**
